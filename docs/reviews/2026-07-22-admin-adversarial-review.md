## 미수용 — 근거 기록

- **파기 후 `preferred_contact`·`marketing_*`의 DB 평문 소거** — 마케팅 동의 이력은 합법적 보존 대상일 수 있어 소거는 정책 판단 사안이며, `preferred_contact IN(...)` CHECK 제약상 마이그레이션이 필요합니다. 표시 레이어 은닉으로 갈음했습니다.
- **검색 접근 감사 로그** — PII 접근 이벤트인 것은 맞으나 신규 기능 범위.
- **라벨맵 `Object.hasOwn` 견고화** — 값이 전부 DB enum이라 도달 불가.
- **이메일 형식 힌트·종결 체크박스 상시 노출** — 무JS SSR 설계 트레이드오프. 정확성·UX 에이전트도 수용 가능으로 판정.
